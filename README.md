# VDownloader 下載

Chrome 擴充功能：偵測網頁上正在播放的影片，一鍵下載成 MP4。

## 下載最新版：v0.8.2

**[⬇ 下載 VDownloader-v0.8.2.zip](https://github.com/leowei813/VDownloader-Releases/releases/download/v0.8.2/VDownloader-v0.8.2.zip)**

所有版本：[Releases](https://github.com/leowei813/VDownloader-Releases/releases)

## 安裝

1. 下載上方的 zip，解壓縮，會得到 `VDownloader` 資料夾。**放在固定位置，之後不要移動。**
2. Chrome 網址列輸入 `chrome://extensions`，開啟右上角「**開發人員模式**」。
3. 按「**載入未封裝項目**」，選擇 `VDownloader` 資料夾。
4. 點工具列的拼圖圖示，把 VDownloader **固定**到工具列。

## 自動更新

安裝後到 VDownloader 的「設定」→「自動更新」，按「**授權資料夾…**」並選擇上面的 `VDownloader` 資料夾（Chrome 詢問時選「每次造訪時都允許」）。之後有新版本時會自動下載、驗證並更新，不必再手動下載。

## 功能

- HLS 串流（.m3u8，含 AES-128 加密）無損轉成 MP4；MP4／WebM 直連影片直接下載
- 影片預覽縮圖與時長、選擇畫質
- 暫停／繼續，關閉瀏覽器後自動續傳
- 自訂儲存位置（不變更 Chrome 的下載位置）、存檔時不跳出下載通知
- 工具列圖示顯示下載進度

> 不支援 DRM 保護的內容。請遵守著作權法與各網站的服務條款，僅下載供個人離線觀看。
